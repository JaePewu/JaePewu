## Proyectos destacados

### 🛍️ Catálogo Administrativo Ecommerce - Django

Aplicación web desarrollada con Django para administrar un catálogo de productos de un ecommerce.  
Este proyecto permite gestionar productos, categorías, stock, imágenes, fotografías adicionales y vista de detalle del producto.

**Funcionalidades principales:**

- Crear, listar, editar y eliminar productos.
- Asociar productos a categorías.
- Administrar stock desde el catálogo y desde el detalle.
- Subir imagen principal y fotografías adicionales.
- Visualizar detalle completo del producto.
- Mostrar galería de imágenes tipo carrusel.
- Mostrar notificaciones flotantes para acciones administrativas.
- Utilizar el panel administrativo de Django.

**Tecnologías utilizadas:**  
`Python` `Django` `PostgreSQL` `HTML` `CSS` `Git` `GitHub`

🔗 Repositorio: [catalogo-ecommerce-django](https://github.com/JaePewu/catalogo-ecommerce-django)

---

### ☁️ Java Soluciones en la Nube - TechStore

Proyecto académico desarrollado junto a Vicky, enfocado en soluciones en la nube utilizando Java, Spring Boot y arquitectura basada en microservicios.  
El proyecto permitió trabajar con servicios independientes, API Gateway, contenedores Docker, pruebas de endpoints y despliegue o configuración de componentes en AWS.

**Funcionalidades y aprendizajes principales:**

- Desarrollo de microservicios con Java y Spring Boot.
- Organización por capas: controller, service, repository y model.
- Creación y prueba de endpoints REST.
- Uso de API Gateway para centralizar rutas.
- Contenerización de servicios con Docker.
- Pruebas funcionales con Postman.
- Trabajo con bases de datos y configuración de variables de entorno.
- Aproximación a despliegue cloud usando AWS.
- Trabajo colaborativo y documentación técnica.

**Tecnologías utilizadas:**  
`Java` `Spring Boot` `Maven` `Docker` `AWS` `API Gateway` `Postman` `SQL` `Git` `GitHub`

🔗 Repositorio: [techstore](https://github.com/JaePewu/techstore)
